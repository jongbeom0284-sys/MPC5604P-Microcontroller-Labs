# 개발 도구와 복원 방법

## 사용한 도구

- **CodeWarrior**: Freescale MPC5604P용 C 프로젝트의 편집·빌드·다운로드 환경. 기본 예제의 `readme.txt`가 이 타깃을 명시하고 있습니다.
- **FreeMASTER 2.0**: 보드와 통신하며 변수 값을 관찰·변경하는 도구. `.pmp`는 이 도구의 프로젝트 설정입니다.
- **MPC5604P 보드 및 연결 장비**: 실제 레지스터·인터럽트·모터 구동 기능은 보드와 주변 회로가 있어야 확인할 수 있습니다.

## 기존 수업 환경에 작업본 연결

1. 본인이 사용 가능한 MPC5604P 기본 예제와 CodeWarrior 환경을 준비합니다.
2. 기본 예제를 복사한 뒤 해당 프로젝트의 `src/main.c`를 이 저장소의 `src/main.c`로 교체합니다. GPIO·ADC 초기 실습을 확인하려면 대신 `labs/adc-gpio/main.c`를 사용합니다.
3. `patches/uart-19200.patch`를 참고해 기본 `init_base.c`의 LINFlex baud 설정을 맞춥니다. 해당 변경은 64MHz 가정 주석에서 integer divider 208을 선택하는 내용입니다.
4. 보드 target·startup·장치 헤더·linker 설정을 확인하고 전용 컴파일러에서 빌드합니다. GitHub에 올린 소스만으로 일반 PC의 GCC에서 보드용 실행파일이 만들어지지는 않습니다.
5. FreeMASTER에서 `freemaster/Example.pmp`를 열고 재빌드한 ELF 경로와 실제 연결 장치를 지정합니다. 설정 파일에는 `./bin/internal_FLASH.elf`라는 상대 참조가 있습니다. 해당 ELF는 저장소에 포함하지 않았습니다.

## 소스와 FreeMASTER 설정의 관계

`.pmp`는 바이너리 형식이지만 GitHub에 보관할 수 있습니다. 코드 리뷰는 텍스트인 `.c`와 문서에서 하고, `.pmp`는 실제 도구에서 열어 사용합니다. 새로 빌드하면 변수 주소가 달라질 수 있으므로 기존 설정만으로 보드 값이 정확히 연결된다고 가정하지 않습니다.

구버전 CodeWarrior에서 한글 주석이 깨지는 경우, UTF-8 공개본의 사본을 해당 IDE가 사용하는 CP949로 저장하면 됩니다. 레지스터 코드와 파일 내용을 임의로 바꿔 문제를 해결한 것으로 간주하지 않습니다.

## 확인 범위

공개 정리 시 수행한 것은 기본 압축본과의 파일 비교, 소스 인코딩의 손실 없는 변환 확인, FreeMASTER 설정의 원본 보존, 보고서 발췌 화면의 육안 확인입니다. CodeWarrior 재빌드·보드 다운로드·계측을 다시 수행하지 않았습니다.

현재 `src/main.c`는 여러 실습 단계가 함께 남은 스냅샷입니다. 예를 들어 `PWMISR()`의 `Errdetect;`는 함수 호출문이 아니며, SPI 송신값·ADC 채널 설정도 별도 SPI 보고서의 시점과 다를 수 있습니다. 실습 재개 시 이런 부분과 controller enable·gain 설정을 먼저 검토해야 합니다. 이번 공개 작업에서는 원래 동작을 바꾸지 않았습니다.
